## 🚀 Projets en vedette

### 🎬 [VideoStreaming Platform](https://github.com/NININAHAZWE04/videostreaming)

> Plateforme de streaming vidéo distribuée — architecture Java RMI + HTTP, authentification JWT, système d'abonnements avec essai gratuit 14 jours et paiement cash, panel d'administration complet.

![Java](https://img.shields.io/badge/Java_21-ED8B00?style=flat-square&logo=openjdk)
![React](https://img.shields.io/badge/React_18-61DAFB?style=flat-square&logo=react&logoColor=black)
![H2](https://img.shields.io/badge/H2_Database-1A1A2E?style=flat-square)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)
![MIT](https://img.shields.io/badge/License-MIT-green?style=flat-square)

**Ce que ce projet démontre :**
- Architecture distribuée : annuaire RMI, serveurs HTTP multi-ports, streaming Range
- Auth complète : JWT HS256 maison, PBKDF2-HmacSHA256, tokens téléchargement usage unique
- Base de données H2 avec schéma auto-migré : users, subscriptions, payments, view events
- SSE temps réel : remplace le polling client, bus d'événements centralisé
- Panel admin React : Dashboard KPIs, gestion utilisateurs, approbation paiements cash
- Client React Netflix-style : contenu verrouillé/gratuit, modal abonnement, progression
